# SwipeStudy - Skeleton Project

This skeleton project is provided for Module 7 of the Mobile Application Development course.

SwipeStudy is a simple flashcard study app focused on gestures, animations, and interactive mobile UI behavior using SwiftUI.

The project includes:

* Basic SwiftUI project structure
* A flashcard model
* Sample flashcard data
* A clean starting version of the main app file
* A temporary starting view
* Hard-coded flashcard content for the study session

The goal of this skeleton project is to reduce setup time so we can focus on building the SwipeStudy application features.

Throughout the module, you will implement:

* Main flashcard study view
* Session state for the current card
* Local counters for Got It, Review, and Favorites
* Reusable stats header view
* Reusable flashcard view
* Tap gesture to flip between question and answer
* Drag gesture to move the card
* Swipe right action for Got It
* Swipe left action for Review
* Long press gesture to mark a card as favorite
* Card movement animation
* Card flip animation
* Swipe labels for Got It and Review
* Reset Session feature
* Completion view for the end of the deck

Before starting, open the project in Xcode and make sure the project builds successfully.

Once the project is ready, open the main SwiftUI app file and follow along with the module videos to build the SwipeStudy SwiftUI application step by step.
